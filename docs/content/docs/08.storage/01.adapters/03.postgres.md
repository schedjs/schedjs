---
title: Postgres
description: pg driver — same contract, placeholder syntax and native booleans
---

```bash
npm install @schedjs/storage-postgres
```

```ts
import { Pool } from 'pg';
import { createPostgresStorage } from '@schedjs/storage-postgres';

const pool = new Pool({ connectionString: 'postgres://user:pass@db:5432/sched' });
const storage = await createPostgresStorage(pool);
```

Same pattern as MySQL/MariaDB: versioned migrations applied on open
(`sched_schema_version`), atomic claim via conditional `UPDATE`, JSON-as-TEXT,
placeholder `$1..$n`, upsert `ON CONFLICT … DO UPDATE SET … EXCLUDED`. The
contract suite runs against Postgres 16 the same way it runs against SQLite,
MySQL/MariaDB and Mongo.

## Known gotchas

- `pg` returns `BIGINT` columns as **strings** — the adapter converts explicitly
  in its row mappers instead of mutating the global type parser (a host app
  sharing the pool may rely on string bigints).
- `paused`/`disabled` are native `BOOLEAN` (the one real type difference from
  MySQL's `TINYINT(1)`); everything else — timestamps, JSON, locking — is
  encoded identically to the other adapters.
- No `SERIAL`/identity columns: task and run keys are TEXT primary keys
  (run ids are generated by the engine).
