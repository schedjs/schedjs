---
title: SQLite (default)
description: The embedded default — zero-config, one file, inside @schedjs/core
---

```ts
import { DatabaseSync } from 'node:sqlite';
import { createSqliteStorage } from '@schedjs/core';

const storage = createSqliteStorage(new DatabaseSync('sched.db'));
```

One file, no server, migrations applied on open. Right choice for a single daemon.
SQLite lives in `@schedjs/core` — nothing extra to install.

## Locking

Claim is a conditional `UPDATE … WHERE locked_at IS NULL` with a `changes`-count
check — the same atomic semantics every adapter implements (see the
[contract suite](../custom#the-contract-suite-is-the-insurance)).
