# @schedjs/ui

[![npm](https://img.shields.io/npm/v/@schedjs/ui)](https://www.npmjs.com/package/@schedjs/ui)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

Admin web UI for the [`@schedjs/core`](https://www.npmjs.com/package/@schedjs/core)
cron scheduler — framework-agnostic Lit web components plus a standalone
dashboard (`sched-ui serve`).

## Features

- Task / run status at a glance.
- Trigger, pause, resume from the browser.
- Embeddable as web components in any app.

## Install

```bash
npm install -g @schedjs/ui
```

## Usage

```bash
sched-ui serve                 # standalone dashboard
```

Or embed the web components directly:

```js
import '@schedjs/ui'
```
